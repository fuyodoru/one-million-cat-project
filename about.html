ABOUT THE PROJECT

One Million Cat Project is a community-driven project dedicated to counting the cats of the world.

01 / THE PROJECT

WHAT IS ONE MILLION CAT PROJECT?

How many cats are there in the world? We don't know yet.

One Million Cat Project is an attempt to build a community-powered map of cat sightings around the world.

Anyone can contribute a sighting by reporting how many cats they saw and where they saw them. Each approved contribution becomes part of the global count.

The goal is simple: count one million cats.

03 / PRIVACY

KEEPING LOCATIONS PRIVATE

Cat sightings are displayed using publicly visible coordinates that are slightly offset from the original location.

This helps prevent a reported location from revealing an exact address while still allowing the map to show where cats have been spotted.

04 / COMMUNITY

BUILT AROUND CONTRIBUTIONS

The project grows through community contributions. A single cat may seem insignificant, but a million cats can tell a very different story.
